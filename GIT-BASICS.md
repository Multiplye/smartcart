# SmartCart — Checking What Changed (Git Basics)

You now have a safety net. Git records every version of your code, so you can
always see what changed and undo mistakes.

---

## The only 3 commands you need day to day

### 1. What have I changed since the last save point?

```powershell
cd C:\Users\ashim\Downloads\smartcart
git status
```

Files listed in **red** = changed but not saved.
Empty output = nothing changed since your last commit.

### 2. What exactly changed inside those files?

```powershell
git diff
```

Green lines starting with `+` were **added**.
Red lines starting with `-` were **removed**.

This is the real answer to "what was just updated?" — it shows the actual lines.

### 3. Save a checkpoint

```powershell
git add .
git commit -m "Describe what you did"
```

Do this whenever something works. It is your undo point.

---

## See the history

```powershell
git log --oneline
```

Like a list of save points, newest first.

```powershell
git show HEAD
```

Shows everything in the most recent commit.

```powershell
git log --oneline --stat
```

History plus which files each commit touched.

---

## Undo something

| Situation | Command |
|---|---|
| Changed a file, want it back as it was | `git checkout path/to/file` |
| Changed things, want to undo **everything** unsaved | `git checkout .` |
| Undo the last commit, keep the changes | `git reset --soft HEAD~1` |

> Careful with the last one — it rewrites history.

## What is NOT tracked (on purpose)

Defined in `.gitignore`:

- `backend/venv/` — huge, and rebuilt from requirements
- `node_modules/` — huge, restored by `npm install`
- `backend/instance/*.db` — **holds real user data and password hashes**
- `dist/` — generated by `npm run build`

The database is deliberately excluded. Each person keeps their own local copy
and re-seeds it with `python import_products.py`.

## If you want to share the project later

```powershell
git remote add origin <your-repo-url>
git push -u origin master
```

Make a free repo on GitHub, paste its URL, and your code is backed up online.
Worth doing before your submission — a laptop failure would otherwise lose
everything.

## Quick reference

```powershell
git status              # what changed
git diff                # the actual changes
git add .               # stage everything
git commit -m "message" # save a checkpoint
git log --oneline       # history
git checkout <file>     # undo changes to one file
```
